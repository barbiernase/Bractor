Semantische Blöcke · 3

Der allgemeine Graph

Ein Ausgang passt nur an einen Eingang derselben Farbe.

  • Command geht an genau ein Aggregat.
  • Event geht an beliebig viele Projektionen und Funktionen.
  • Hinweis geht an Funktionen oder Clients.
  • Query geht an genau einen Reader oder ein Aggregat.
  • Frist geht an die Uhr und wird zum Command an dasselbe Aggregat.
  • Antwort geht an den fragenden Client.

ImagePair

Anlegen oder ergänzen. Mit dem zweiten Bild ist das Paar komplett: ein if, kein Prozess.

public IEnumerable<OneOf<ImagePairErstellt, BildVerfuegbar,
    ImagePairKomplett, BildVersionBereitsVerfuegbar>> Decide(NimmBildAuf cmd)
{
    var neu = State.Version == 0;
    if (neu)
        yield return new ImagePairErstellt(cmd.AggregateId, cmd.PairKey, …);
    else if (State.GetBild(cmd.Version) != null)
    {
        yield return new BildVersionBereitsVerfuegbar(cmd.Version);
        yield break;
    }

    yield return new BildVerfuegbar(cmd.Version, cmd.Meta, cmd.Pfad, regionen);

    var andere = cmd.Version == BildVersion.Dc0 ? BildVersion.Dc2 : BildVersion.Dc0;
    if (!neu && State.GetBild(andere) != null)
        yield return new ImagePairKomplett();
}
